# caniuse.rs

caniuse.rs helps Rust users find features and identify the Rust versions that provide them.

Users can search for a feature, open its reference page, follow documentation and source links, browse recent or unstable features, and explore tracked features by release. The release atlas provides a horizontal view of Rust's release history. Version and feature links remain direct entry points.

The project data is a tracked feature reference, not a complete copy of Rust release notes. Missing changelog categories remain unclassified. Release summaries and code examples are optional; the interface must work without them.
